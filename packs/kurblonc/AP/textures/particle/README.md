# Falling leaves

`leaf_0.png` through `leaf_11.png` are copied unchanged from the owner's local Forager Minecraft pack (`forager/Forager/assets/minecraft/textures/particle/`). Kurblanc reduces each shape to half its source dimensions (rounded up) using nearest sampling, then recolours it at load time from each tree canopy, retaining alpha and relative shading. The same 2× source-pixel scale as terrain and trees, nearest sampling and snapped edges preserve the world pixel grid.
